# Acervo de fotos — Neoquim

As 17 fotos originais da unidade de Itaquaquecetuba, como entregues pela Neoquim.

Esta pasta fica **fora de `public/`** de propósito: tudo que entra em `public/` é servido
publicamente e vai inteiro para o deploy. Aqui o acervo fica versionado como fonte, sem peso no
bundle.

Para usar uma foto no site, copie para `public/images/` com nome descritivo em kebab-case e
referencie pela constant da página ou do produto — nunca aponte o `src` para esta pasta.
